# 抖音私信扩展 v0.1.0

2026-10-03。普通账号、浏览器交互；指定名单发送及关键词自动回复。

外部执行提案：平台 `docs/adr/0036-bounded-local-douyin-private-messaging.md`（提议，未发布）。

## 所有权和授权

本地 `mcp/douyin-dm` 拥有私信任务草稿、去重账本和脱敏事件；不访问平台业务表、不新增 Schema、不拥有平台身份。沿用平台 ADR-0005 的类型化受控执行原则，官方 Harness、现有 Local Runner 和桌面升级文件不修改。

仅供操作者单独启动的、单主体 DSH 实例使用：本地可信配置固定 subject、device、抖音账号和两个浏览器 tab；模型参数不能选择主体、账号、URL、Cookie、脚本或选择器。不能挂到可切换租户的共享桌面会话。未来正式桌面集成必须由平台签发账号/设备授权并随注销、主体切换停止任务；本版本不冒充此授权。

真实发送默认关闭。专用 Profile 关闭第三方遥测，强制 ask 审批并将工具范围限定为四个私信工具，拒绝 Shell、通用浏览器和其他 MCP 绕过。DSH pre-execute 必须确认启动工具；批准绑定不可变预览 ID，含账号、精确名单/规则、数量、间隔及有效时间。未知扩展工具默认拒绝。启动后一次授权仅覆盖该冻结计划及限额。暂停立即改变停止标志，已经进入浏览器发送调用的消息可能完成。

## 契约

`douyin_dm_preview`：outbound 的 secUid 名单和一条文本；reply 的有序 contains/reply 规则（首条匹配）。最长 500 字、50 人、50 次发送、30 秒间隔、1 小时时长。预览不连接浏览器。

`douyin_dm_start`：只接受 previewId。开启自动执行前检查配置账号；回复模式先把已加载消息作为基线，只处理此后加载的新消息。`douyin_dm_status` 返回脱敏状态；`douyin_dm_pause` 停止任务。

本地 Chrome CDP 只允许显式 loopback 地址、固定 targetId、`https://www.douyin.com` 页面；不启动浏览器、不读取 Cookie、不导出登录状态、不执行模型代码、不使用逆向接口/签名或验证码绕过。页面选择器由人工校准配置，参考工具的输入框模式只是历史线索，不能作为现行 DOM 验收。独立 inbox tab 保持消息页，sender tab 用于主页及私信对话；两者都须证明当前账号。

自动回复只覆盖 inbox tab **当前已加载 DOM 中**带稳定消息 ID 和 secUid 的入站消息；并非全量后台收信接口。不自动遍历未加载会话。选择器未校准时不可宣称普通账号全会话自动回复已完成。

## 幂等和恢复

发送前原子写入 attempting；进程中断、CDP 超时或无法确认发送后均标为 unknown，停止所有后续发送，不自动重试。同账号同收件人同文案不重复名单发送；入站稳定 ID 最多回复一次。重新启动进程不恢复执行授权。状态文件独占锁拒绝多进程，禁止跨主体复用。账本达到容量停止；不静默清除历史。

浏览器确认条件是当前收件人一致且发送后新增了有稳定 ID、文本相等的出站 DOM 项；这表示页面确认发送，不能证明对方已收到/已读。登录、账号改变、验证码或 DOM 不匹配均停止。

状态文件包含名单/话术，是私有本地工作数据，放在忽略的 `work/`，限制 Windows 文件 ACL，不进入 Git。事件不记原文/收件人。未解决的 unknown 需人工核对抖音记录和私有账本，不提供清空去重工具。

## 验收及交付边界

离线验证：名单去重、预览冻结、关闭 live 时拒绝、批准耗尽、关键词规则、历史消息不回复、跨主体拒绝、并发暂停、限速/限量/时长、崩溃及 unknown 禁止重发、MCP transport 与审批钩子、loopback/CDP 及 DOM 失败。

真实账号联调需另行明确授权指定测试账号和收件人；至少手动校准账号/收件人/入站/出站/验证码选择器，验证名单发送、收到新消息回复、登出和验证码停止。此任务不运行真实发送，不生成/安装新版桌面安装包。关闭独立 Profile 即回退，不改变平台服务和 Schema。
