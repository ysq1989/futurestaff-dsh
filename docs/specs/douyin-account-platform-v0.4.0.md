# 抖音账号与平台环境 v0.4.0

平台插件Host配置 `environment: production` 指定 `https://platform.fsstory.net`；省略配置保留历史DEV用于兼容离线测试。DEV与正式源固定允许名单，API、PKCE和聊天禁止任意端点、禁止重定向。`platform-dev` 本机路由与服务名称保留兼容，不代表网络仍访问DEV；新增 `/_futurestaff/platform-dev/environment` 返回无凭据环境标签。

正式环境使用独立OS保护会话键，必须重新登录；不会把既有DEV令牌发给正式平台。聊天模型列表包含默认项与当前主体可用模型，选择时及每次推理重新验证目录授权；默认模型选择在当前进程按用户/主体保存，重启回到平台默认。抖音分析模型仍由SQLite保存并按当前目录重新校验。旧会话或工作区数据不自动跨环境采用。

平台租户Logo可以为站内根相对资源路径。API适配层按当前可信平台源规范化为绝对URL后再发布给Renderer；协议相对URL、反斜线、脚本协议及跨源相对解析仍拒绝。租户UUID、成员角色、模型授权和会话契约不因资源路径兼容而放宽。

本机工作区增加 `account-open`、`account-check`、`account-disconnect` 三个无附加字段动作。Renderer不能提供端点、账号ID、路径、选择器或脚本。Host基于平台源、可信tenant/user散列分区浏览器Profile；状态为 disconnected / awaiting-login / connected，公开响应只含状态及核对出的账号ID。登录由操作者在可见专用浏览器内（优先 Chrome，未安装时回退 Edge）使用抖音扫码/手机入口完成；保留本机Cookie，但不将其导出或上传。

账号检查导航专用tab到公开 `/user/self`，从抖音同源已登录会话的本人账号响应核验 sec_uid，不依赖个人页重定向，也不把任意个人主页 URL 当作登录证明；无证据时不显示已登录。账户状态是最近一次显式检查结果，发送前仍须重新校准验证账号。断开、切换主体和注销撤销发送预览并关闭专用浏览器；断开保留本机登录，下次打开可复用。软件内不保存抖音密码，不绕过验证码。

目前登录浏览器不自动开启发送。已有只读/预览界面可用；连续评论采集、周期任务以及绑定专用浏览器的真实发送DOM校准未完成，真实发送关闭。

登录浏览器启动为单个空白标签，复用该标签打开个人页；检查期间及检查完成均显示明确反馈。页面或网络核验失败返回 ACCOUNT_CHECK_FAILED 并保留浏览器供重试。


登录检查补充（2026-10-05）：只检查当前专用页的同源 authenticated self 响应，不主动刷新或跳转，避免打断扫码与登录回跳。页面执行环境销毁/短暂接口失败在现有时间上限内重试；持续失败仍明确报错并保留浏览器。浏览器进程退出时撤销 active 会话，后续可重新打开；没有以 URL 或 DOM 文本代替身份验证。
