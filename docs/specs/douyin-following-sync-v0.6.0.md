# 抖音一键同步关注账号 v0.6.0

继承 douyin-library-v0.5.0 的本机来源认证、Host 身份和专用浏览器边界。

新增 POST 动作 `{ action: "following-sync" }`，拒绝其他字段；打开本人主页，点击唯一关注入口，确认关注列表区域，自动滚动、去重，核对主页关注计数或明确结束标记，重新确认登录身份后原子添加到既有 account watches。默认间隔 600 秒，重复记录保持已有设置。超出 500 条容量或列表无法确认完整时不导入。最大采集时段 90 秒，不保存部分结果。

响应增加 `followingSync: null | { running: boolean, count: number, added: number }`。同步期间 GET 不等待本次操作队列，仍校验当前平台权限和会话；进度仅存 Host 内存，注销和刷新会话清除。原选择导入动作保持兼容，手动选择仍为 1–200 条。内部原子批量上限调整为 500，与既有工作区容量一致；SQLite schema 不变。

`LIBRARY_INCOMPLETE` 是固定安全错误码，UI 显示未读取完整且没有导入，并持续显示已读取账号数量。所有链接仍只能来自已证明的本人关注区域，排除整页推荐、隐藏、外站和本人链接。真实站点缺少区域证据或控件唯一性时拒绝并报告；离线浏览器回归不代替真实抖音验收。

本动作同步账号名称和主页，不触发作品/评论持续采集或私信发送。


真实页面补充：支持“关注 (19)”及“关注（19）”计数；对缺少标准 dialog/tabpanel 的 Semi 弹窗，要求唯一选中关注 tab、同 bar 的粉丝计数 tab、唯一 fixed 祖先和空的“搜索用户名字或抖音号”输入框。读取区域是同时包含 tab bar 和搜索框的最近祖先，范围保持在遮罩内；不采用构建哈希 class、不扩展到 body，不读取粉丝页或筛选结果。主页计数尚未 hydration 时等待入口，最多 10 秒；打开后仍验证可读区域。
