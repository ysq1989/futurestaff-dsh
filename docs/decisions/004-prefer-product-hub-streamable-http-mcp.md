# ADR-004: Prefer the authenticated Product Hub Streamable HTTP MCP

## Status

Accepted

## Date

2026-08-28

## Context

M2 introduced a four-tool stdio MCP and an isolated provisional REST adapter because the real Selection Center contract was not yet available. The deployed FutureStaff Product Hub now exposes a versioned, tenant-key-protected Streamable HTTP MCP at `/api/product-hub/mcp`. It owns product, pool, H5, design, release, audit, and tenant-isolation behavior.

Maintaining a second REST-to-MCP translation would duplicate schemas and observable behavior, lag behind Product Hub capabilities, and require `futurestaff-dsh` to understand Product Hub persistence semantics.

## Decision

The `futurestaff-alpha` Profile connects directly to the authenticated Product Hub MCP through the official `@deepseek-ai/dsh-mcp-client` Streamable HTTP transport.

- `PRODUCT_HUB_MCP_URL` selects the endpoint.
- `PRODUCT_HUB_AGENT_KEY` supplies the Bearer credential.
- Both values are required before the connection is enabled.
- When the formal Product Hub connection is enabled, the provisional Selection Center stdio connection is disabled to avoid duplicate tools.
- The provisional adapter remains in the repository as a contract fixture and fallback while migration is completed.

## Alternatives Considered

### Rewrite the provisional HTTP adapter for Product Hub V1

Rejected because it would duplicate the server's MCP schemas, error semantics, authentication, audit behavior, and future H5/design tools.

### Connect to unversioned internal Agent routes

Rejected because those routes rely on a caller-supplied tenant header and are not the authenticated public Agent contract.

### Remove the provisional adapter immediately

Rejected because local tests and disconnected development still need a deterministic fallback until the formal integration has completed live acceptance.

## Consequences

- Product Hub remains the source of truth for its public tool contract.
- DSH gains new Product Hub tools without changes to DSH Core or this repository's TypeScript adapter.
- A Product Hub Agent Key is now a deployment secret and must never be committed or logged.
- Tool names use the `mcp__product-hub__*` namespace generated by DSH.
- Changes to the upstream tool list are observable by the model and require acceptance testing before production rollout.
